# Home Server AutoInstall

Infrastructure-as-code for the GTX 1070 home-server appliance. The repository is being scaffolded around Ubuntu Autoinstall, Ansible, Docker Compose, Tailscale, Cockpit, Arcane, Beszel, Uptime Kuma, and Restic.

The deployment is intentionally not ready to apply yet. See the implementation plan and safety gates in the forthcoming scaffold before connecting this repository to a host.
